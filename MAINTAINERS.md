gitr has one maintainer. Review comes from one person, and a pull request waits
when that person is busy — there is no second reviewer to fall back on. Say so
here rather than let a contributor infer neglect from silence.

`.github/CODEOWNERS` routes review automatically. This file answers what routing
cannot: who decides, and who to name when something needs a decision rather than
a review.

## Getting a change in

Open an issue to report or propose, a pull request to change. Both are read, and
a pull request without a matching issue is fine — an issue is for discussion, not
for permission.

There is no private contact route today. Nothing that needs to stay private,
including a security report, has anywhere to go yet.
